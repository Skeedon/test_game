# Mini Garage Tycoon

Небольшая браузерная игра об автомастерской. React, TypeScript, Vite; вся графика — CSS и собственные SVG. Без backend, внешних изображений, API и платных зависимостей.

## Запуск

Требуется Node.js 18+ и npm.

```sh
npm install
npm run dev
```

Откройте адрес, указанный Vite (обычно http://localhost:5173).

```sh
npm test          # unit-тесты игровых операций
npm run build     # TypeScript и production-сборка
npm run preview   # просмотр production-сборки
```

## Как играть

Начальный баланс — $5 000. Выберите подержанный автомобиль на авторынке: гараж вмещает одну машину. Отремонтируйте двигатель, кузов или подвеску, затем продайте автомобиль. Стоимость ремонта зависит от износа и рыночной стоимости; продажная цена — от среднего состояния. Прибыль учитывает покупку и все ремонты. Новые предложения можно получить бесплатно кнопкой обновления рынка. Прогресс автоматически сохраняется в localStorage этого браузера.

## Структура

- `src/App.tsx` — адаптивный интерфейс и подключение состояния.
- `src/components/CarArt.tsx` — единый компонент изображения машины для гаража и карточек.
- `src/components/carAssets.ts` — привязка иллюстраций к марке и модели.
- `public/assets/cars/` — четыре самостоятельных SVG-изображения машин на прозрачном фоне.
- `src/styles.css` — дизайн, адаптивность, focus-состояния и уменьшение анимаций.
- `src/game/game.ts` — игровая модель, расчёты, операции, проверка и сохранение прогресса.
- `src/game/game.test.ts` — проверки покупок, ремонта, продаж, экономики и сохранений.

Изменения состояния проходят через `transact`, компоненты используют типизированные сущности `Car`, `Game`, `Action`. Журнал хранит 12 последних операций (интерфейс показывает 5). Сохранения проверяются перед загрузкой; повреждённые данные заменяются новой игрой. Если браузер запрещает запись, появляется уведомление, игра продолжает работать в памяти.

Расчёты: продажная цена равна рыночной стоимости × (0,35 + 0,65 × среднее состояние / 100). Ремонт двигателя стоит 0,3% рыночной стоимости за каждый процент износа; кузова и подвески — 0,2%. Все суммы округляются до целых долларов. Ремонт полностью восстанавливает выбранный узел; его расходы входят в итоговую прибыль.


## Изображения машин

Golf IV, BMW E46, Mazda MX-5 и Honda Civic нарисованы в одном полуреалистичном векторном стиле: строго сбоку, передняя часть слева, одинаковые свет и линия колёс. MX-5 показана с закрытым мягким верхом. Каждый SVG имеет прозрачный фон и холст 800 × 320; его можно использовать отдельно в других экранах без потери качества. Растровые изображения и внешние сервисы не требуются.

В React используйте `<CarArt car={car} />`. Реестр `carAssets.ts` сопоставляет марку и модель, поэтому иллюстрации работают и для ранее сохранённых машин. Пути учитывают базовый URL Vite. Для новой модели добавьте SVG в `public/assets/cars/` и запись в реестр. Неизвестные модели используют прежний SVG с цветом и типом кузова; пустой гараж сохраняет полупрозрачный силуэт.
